# تمكن بلس · مسار التمكّن التدريبي

نظام تفاعلي يستورد درجات المتدربات من Blackboard ويحوّلها إلى **خطط دعم تدريبية**،
ويكشف المهارات التي تحتاج إلى تطوير، ويسهّل متابعة أثر التدريب.

## المميزات

- ✅ حسابات متعددة للمدربات (Supabase Auth)
- ✅ إدارة المقررات والشعب
- ✅ استيراد المتدربات من Excel/CSV
- ✅ إدخال أسئلة الاختبار (مرتبطة بمهارة وموضوع)
- ✅ استيراد درجات المتدربات من Blackboard
- ✅ تحليل الدرجات ومصادر القياس التدريبية
- ✅ قياس التحسّن بين مصادر الدرجات
- ✅ توليد خطة دعم شخصية + رمز QR خاص
- ✅ بوابة متدربة (بدون تسجيل دخول) لتعبئة الخطة واعتمادها
- ✅ تصدير الخطة كملف PDF
- ✅ قياس التحسّن بين الاختبارات

## المتطلبات

- Node.js 18+
- حساب على [Supabase](https://supabase.com)

## الإعداد

### 1) تثبيت الحزم

```bash
npm install
```

### 2) إعداد Supabase

أنشئي ملف `.env` في جذر المشروع:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

طبّقي ملفات `supabase/migrations` على مشروع Supabase بالترتيب من `001` إلى `007`.
الهجرة `004` تنشئ مخزن صور الترويسة والتوقيع، وتحدّث درجات الخطط القديمة إلى قيمها الخام.
الهجرة `005` تسمح بأكثر من نموذج دعم داخل المقرر مع الاحتفاظ بالنماذج والخطط الموجودة، وتجهز bucket صور الترويسة والتوقيع وأعمدتهما.
الهجرة `006` تعيد التحقق من وجود مخزن الصور وأعمدة الترويسة والتوقيع، حتى لو كانت الهجرة `005` قد طُبقت قبل إضافة إعدادات الصور.
الهجرة `007` تنشئ دالة فحص بسيطة لا تقرأ بيانات التطبيق، وتسمح لـ GitHub Actions بتشغيل استعلام قاعدة بيانات يومي لمنع الخمول على خطة Supabase المجانية.

بعد تطبيق الهجرة `007`، أضيفي في إعدادات المستودع على GitHub السرّين `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` (نفس القيم المستخدمة في `.env`)، ثم شغّلي `Keep Supabase Active` يدويًا مرة واحدة من تبويب **Actions** للتحقق من نجاح الاتصال. يعمل الفحص تلقائيًا يوميًا عند 08:17 UTC. لا تضعي مفتاح `service_role` في GitHub Actions؛ يستخدم الفحص مفتاح `anon` فقط ولا يصل إلى جداول بيانات المتدربات.

### 3) التشغيل

```bash
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```
